# Economy

## 1. 핵심 재화

Project Grow의 현재 핵심 재화는 골드, 소환 재화, 캐릭터 조각의 3종으로 구성한다.

성장석과 강화석은 사용하지 않는다.

## 2. 골드

### 역할

캐릭터와 장비의 기본 성장을 담당하는 재화다.

### 사용처

- 캐릭터 레벨업
- 장비 강화

### 주요 획득처

- 전투
- 스테이지 보상
- 방치 보상
- 기타 추후 콘텐츠

## 3. 소환 재화

현재 가칭은 다이아다.

### 사용처

- 캐릭터 소환
- 장비 소환

정확한 명칭, 가격, 획득처는 추후 확정한다.

## 4. 캐릭터 조각

### 역할

해당 캐릭터의 돌파에 사용하는 개별 재화다.

### 사용처

- 해당 캐릭터의 0돌파~5돌파 성장

### 주요 획득처

- 동일 캐릭터 중복 획득
- 기타 추후 콘텐츠

중복 획득 시 지급되는 조각 수량과 확률은 가챠 가격 및 확률 설계 이후 결정한다.
