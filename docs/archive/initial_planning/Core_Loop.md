# Core Loop

## 핵심 플레이 루프

자동 전투
→ 스테이지 진행
→ 전투 실패 또는 보스 도달
→ 직전 스테이지 반복 사냥
→ 보상 획득
→ 캐릭터 성장 및 파티 조정
→ 재도전
→ 상위 스테이지 진행

## 실패 후 성장 루프

스테이지 공략에 실패하면 플레이가 멈추지 않는다.

직전에 클리어한 스테이지로 자동 복귀하여 반복 사냥을 진행하고,
성장에 필요한 자원을 획득한다.

획득한 자원을 이용해 캐릭터를 성장시키거나
파티 구성을 변경한 뒤 다시 도전한다.

## 핵심 방향

- 자동 전투의 편의성을 유지한다.
- 실패해도 성장 루프가 계속된다.
- 파티 구성에 전략적인 선택 요소를 제공한다.
- 추천 직업은 강제가 아니라 공략을 유리하게 만드는 선택지이다.
- 보스전에서는 직업 대응과 파티 조합을 통해 공략 전략을 구성한다.
