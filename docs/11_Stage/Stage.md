# Stage

## 챕터 구조

- 챕터는 3개이며, 한 챕터는 일반 스테이지 4개와 보스 스테이지 1개(총 5개)로 구성한다. 전체 15스테이지이다.
- 표기는 `챕터-번호`이다. (예: 1-1 → 1-2 → 1-3 → 1-4 → 1-5(보스) → 2-1)
- 5의 배수 스테이지(1-5, 2-5, 3-5)가 보스 스테이지이다.
- 5개 스테이지마다 배경이 바뀐다.

| 챕터 | 이름 | 보스 |
|---|---|---|
| 1 | 세계수 숲 | 고목 수호자 |
| 2 | 독무 늪지 | 늪의 군주 |
| 3 | 불꽃 협곡 | 용암 군주 |

## 웨이브

- 일반 스테이지는 3개 웨이브로 구성하고, 보스 스테이지는 보스 웨이브가 하나 더 붙는다. (1-1은 일반 몬스터만 3웨이브)
- 웨이브 간 별도의 전환 연출 없이, 현재 웨이브의 적을 전멸시키면 잠깐 뒤 다음 웨이브가 등장한다.
- 웨이브가 넘어갈 때 아군은 최대 HP의 20%를 회복한다.
- 세 번째 웨이브에는 정예 몬스터가 섞여 나오고, 4번째 스테이지부터는 정예가 더 늘어난다.
- 마지막 웨이브를 전멸시키면 클리어한다.

## 제한시간

- 일반 스테이지 150초, 보스 스테이지 240초이다. 화면 위쪽에 남은 시간이 표시되고, 15초 미만이 되면 붉게 바뀐다.
- 시간 안에 적을 모두 처치하지 못하면 "TIME OVER"로 실패한다.
- 기준: 권장 전투력 수준의 파티가 일반 스테이지를 약 80~100초, 보스 스테이지를 약 135~175초에 클리어하도록 시뮬레이션했고, 그 1.5배 정도를 제한시간으로 잡았다.

## 실패 처리

- 파티가 전멸하거나 제한시간이 지나면 실패이고, 직전 스테이지로 후퇴해 반복 사냥한다. (보스 실패 시에도 직전 스테이지)
- 이미 클리어한 스테이지로 후퇴한 경우에는 자동으로 다시 올라가지 않고, 화면의 "▶ N-N 로 넘어가기" 버튼으로 직접 올라간다.
- 최고 클리어 기록은 유지된다.

## 클리어 보상

- 골드: `450 × 스테이지 번호`
- 다이아: 첫 클리어 `100 + 30 × 스테이지 번호` (보스 스테이지는 +300), 반복 클리어는 20
- 클리어하면 보상 창이 뜨고 3초 카운트다운 뒤 자동으로 다음 스테이지로 이동한다. (재도전, 캐릭터 강화 버튼으로 중단 가능)

## 권장 전투력

스테이지 1~15: 500 / 800 / 1,200 / 1,800 / 3,500 / 3,600 / 4,300 / 5,600 / 7,200 / 8,600 / 8,800 / 9,400 / 12,500 / 15,500 / 19,000

파티 구성과 레벨을 바꿔 가며 전투를 시뮬레이션해 정한 값이고, 화면에서 내 전투력과 함께 보여 준다.

## 난이도 상승

- 몬스터 조합과 수, 정예 몬스터의 비중, 보스 능력치를 챕터가 오를수록 높인다.
- 몬스터 능력치는 [Monster.md](../10_Monster/Monster.md)를 참고한다.

## 정식 버전 방향

- 챕터를 더 늘리고 챕터당 일반 스테이지를 10개 안팎으로 확장하는 안을 검토한다.
