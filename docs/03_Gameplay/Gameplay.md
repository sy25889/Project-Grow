# Gameplay

## 기본 플레이

- 가로형 화면의 방치형 RPG
- 최대 4명의 캐릭터로 파티를 구성한다. (한 직업당 1명)
- 기본 공격은 자동으로 사용한다.
- 일반 스킬은 쿨타임이 차면 자동으로 사용하며, "스킬 수동"으로 바꾸면 쿨타임이 찬 스킬을 직접 눌러 사용한다.
- 배속 x1 / x2 / x3을 지원한다.

## 스테이지 진행

- 스테이지는 `1-1 → … → 1-5(보스) → 2-1 …` 순서로 자동 진행한다. 자세한 내용은 [Stage.md](../11_Stage/Stage.md)를 참고한다.
- 클리어하면 보상 창이 뜨고 3초 카운트다운 뒤 다음 스테이지로 자동 이동한다. 창의 "재도전", "캐릭터 강화" 버튼으로 멈출 수 있다.
- 방치형이므로 보상을 받으려고 반드시 눌러야 하는 구조는 두지 않는다. (미션 보상은 예외로, 한 번에 하나씩 직접 수령한다.)

## 실패 처리

- 전멸하거나 제한시간(일반 150초, 보스 240초)을 넘기면 직전 스테이지로 후퇴하고 그곳에서 반복 사냥한다.
- 이미 클리어한 스테이지로 후퇴하면 자동으로 올라가지 않고, "▶ N-N 로 넘어가기" 버튼으로 직접 올라간다.
- 최고 클리어 기록은 유지된다.

## 튜토리얼

- 처음에는 B등급 전사 1명으로 1-1을 진행하고, 메뉴는 잠겨 있다.
- 1-1을 클리어하면 소환 → 편성 → 장비 소환 → 장비 장착 → 출석 → 일일 미션 순으로 메뉴를 하나씩 열어 준다. 튜토리얼 중에는 해당 메뉴 외에는 잠긴다.
- 던전, 장비 분해, 새 던전 해금도 각각 해금 시점에 튜토리얼로 안내한다. 튜토리얼 조작은 실제 자원을 소모하지 않는다.

## 화면 구성

- 왼쪽 위: 챕터·스테이지 선택 칩, 전투력과 권장 전투력, 현재 목표 미션
- 오른쪽 위: 골드·다이아, 남은 시간, 스킬 자동/수동, 배속, 설정
- 아래: 파티원 HP·스킬 쿨타임, 메뉴(캐릭터 / 장비 / 소환 / 던전 / 미션)
- 보스 스테이지에서는 보스 HP와 방어 게이지가 위쪽에 표시된다.

## 설정과 저장

- 설정: 화면 흔들림, 데미지 숫자 표시, 이펙트 줄이기(사양이 낮을 때), 타이틀로 이동, 데이터 초기화
- 진행 상황은 브라우저 로컬 저장소에 자동 저장된다. 같은 브라우저에서는 이어하기가 되고, 처음 접속한 브라우저에서는 새 게임으로 시작한다.
- 데이터 초기화는 확인을 한 번 더 거치며, 설정 값은 유지된다.
