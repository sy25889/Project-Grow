# Core Loop

## 핵심 플레이 루프

자동 전투
→ 스테이지 진행
→ 전투 실패 또는 보스 도달
→ 직전 스테이지 반복 사냥
→ 보상 획득
→ 캐릭터 성장 및 파티 조정
→ 재도전
→ 상위 스테이지 진행

## 실패 후 성장 루프

스테이지 공략에 실패하면(전멸 또는 제한시간 초과) 플레이가 멈추지 않는다.

직전에 클리어한 스테이지로 후퇴해 반복 사냥을 하며 성장 자원을 얻고, 그 자원으로 캐릭터를 성장시키거나 파티를 바꾼 뒤 다시 도전한다.

## 성장 가이드 루프 (목표 미션)

유저가 다음에 할 일을 잃지 않도록 목표 미션을 둔다.

전투
→ 미션 달성 (스테이지 클리어, 소환, 강화, 던전 등)
→ 보상 (골드, 다이아, 던전권, 장비 조각)
→ 성장과 새 콘텐츠 해금
→ 다음 미션

- 미션은 한 번에 하나씩 표시되고 끝없이 이어진다.
- 초반 미션은 튜토리얼 순서와 같아서 "무엇을 해야 하는지"를 알려 준다.
- 하루 단위로는 일일 미션, 출석, 일일 던전이 접속 동기를 준다.
- 자리를 비운 동안에는 방치 보상이 쌓인다.

## 핵심 방향

- 자동 전투의 편의성을 유지한다.
- 실패해도 성장 루프가 계속된다.
- 파티 구성(직업당 1명)과 보스 방어 게이지에 전략적인 선택 요소를 둔다.
- 확률과 천장을 공개해 방치형·가챠 게임의 불안을 줄인다.
