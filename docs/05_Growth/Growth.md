# Growth

## 1. 성장 시스템 구성

성장 시스템은 캐릭터 레벨, 캐릭터 돌파, 장비 장착과 강화로 구성한다. 각 성장 요소는 "전투 실패 → 반복 사냥과 방치 보상 → 성장 → 재도전" 루프를 뒷받침한다.

## 2. 캐릭터 레벨업

- Lv.1에서 시작해 최대 Lv.100이다.
- 비용은 골드만 사용한다. 레벨 N → N+1에 `40 + 25 × N` 골드이다. (한 번에 10레벨 올리기 지원)
- 레벨이 오르면 HP와 공격력이 오른다. 방어력 같은 별도 능력치는 두지 않고, 피해 감소는 스킬 효과로 표현한다.
- 레벨당 성장 비율은 직업마다 다르다. (탱커는 HP, 원거리·암살자는 공격력 중심. 표는 [Combat.md](../04_Combat/Combat.md) 참고)
- 성장석은 사용하지 않는다.

## 3. 캐릭터 돌파

- 0돌파에서 시작해 최대 5돌파까지 가능하다.
- 돌파 1회에 해당 캐릭터 조각 20개가 필요하고, 총 100개가 필요하다. 골드는 쓰지 않는다.
- 돌파 단계별 효과:

| 단계 | 효과 |
|---|---|
| ⭐1 | HP·공격력 +20% |
| ⭐⭐2 | 기본 공격 피해 +20%, 공격 간격 -8% |
| ⭐⭐⭐3 | 일반 스킬 위력 +30% (캐릭터별 고유 효과가 있는 경우도 있음) |
| ⭐⭐⭐⭐4 | HP·공격력 +20% 추가 |
| ⭐⭐⭐⭐⭐5 | 고유 특성: 스킬 쿨타임 -25% (캐릭터별 고유 효과가 있는 경우도 있음) |

- 중복 소환을 실패가 아닌 성장 재료로 만들어 소환의 실망감을 줄이는 것이 설계 의도이다.
- 돌파도 레벨업과 같은 "강화" 행동으로 미션에 집계된다.

## 4. 장비 성장

- 캐릭터는 무기와 방어구를 장착한다. 무기는 공격력, 방어구는 HP를 올린다.
- 장비는 +0에서 시작해 +15까지 강화한다. 세부 규칙은 [Equipment.md](Equipment.md)에서 관리한다.

## 5. 전투력(CP)

- 캐릭터 전투력 = round(공격력 × 5 + HP × 0.5)이고, 파티 합계를 화면에 보여 준다.
- 스테이지별 권장 전투력과 함께 표시한다. 권장치 이상이면 초록, 부족하면 붉은색이다.

## 6. 전체 성장 루프

전투
→ 골드와 보상 획득
→ 캐릭터 레벨업
→ 장비 소환
→ 장착과 골드 강화
→ 전투력 증가
→ 상위 스테이지 도전
→ 실패 시 직전 스테이지에서 반복 사냥과 방치 보상
→ 추가 성장
→ 재도전

## 7. 성장 가이드

성장 요소(레벨, 장비, 돌파)는 튜토리얼과 목표 미션으로 순서대로 안내한다. ([Core_Loop.md](../02_Core_Loop/Core_Loop.md) 참고)
