# Equipment

## 1. 장비 구성

- 부위는 무기와 방어구 2개이다. 장신구는 사용하지 않는다.
- 무기는 공격력을 %로 올리고, 방어구는 HP를 %로 올린다.
- 장비는 편성한 캐릭터에게만 장착할 수 있다. 장비 목록에서 장비를 고른 뒤 장착할 캐릭터(직업·등급 표시)를 선택한다.

## 2. 장비 등급과 기본 능력치

| 등급 | 소환 확률 | 무기(+0) | 방어구(+0) | 이름 예 |
|---|---|---|---|---|
| 일반 | 50% | +6% | +8% | 녹슨 검 / 낡은 갑옷 |
| 고급 | 28% | +10% | +14% | 강철 무기 / 강철 방어구 |
| 희귀 | 15% | +16% | +22% | 정령 무기 / 정령 방어구 |
| 영웅 | 6% | +24% | +34% | 세계수 무기 / 세계수 방어구 |
| 전설 | 1% | +36% | +50% | 신화 무기 / 신화 방어구 |

- 강화 1단계마다 능력치가 +12%(기본값 기준) 오른다.

## 3. 장비 강화

- 최대 +15이다. 강화 실패는 없고 성공 확률은 100%이다.
- **+1 ~ +10:** 골드만 사용한다. 비용은 `60 × (등급 번호 + 1) × (현재 강화 + 1)` 골드이다. (등급 번호: 일반 0 ~ 전설 4)
- **+11 ~ +15 (한계 돌파):** 골드와 함께 장비 조각을 사용한다. 단계별 장비 조각은 20 / 30 / 45 / 65 / 90개이다.
- 강화석은 사용하지 않는다.

## 4. 장비 획득

- 장비는 몬스터 처치로 드랍되지 않고, 장비 소환이 주요 획득 방식이다.
- 장비 던전에서도 장비를 얻는다. (던전은 [Economy.md](../06_Economy/Economy.md) 참고)

## 5. 장비 분해

중복되거나 쓰지 않는 장비는 판매 대신 **분해**한다.

- 분해하면 장비 조각(일반 2 / 고급 5 / 희귀 12 / 영웅 30 / 전설 80개)과, 그 장비에 투입한 강화 골드의 50%를 돌려받는다.
- 같은 종류·등급 장비를 수량으로 골라 분해할 수 있고, 등급별 일괄 분해를 지원한다.
- 장착 중인 장비는 분해할 수 없다. 영웅 이상이거나 강화된 장비를 분해할 때는 확인 창을 띄운다.
- 장비 조각은 분해와 일부 미션 보상으로만 얻고, 한계 돌파에만 사용한다.
- 같은 장비를 합성하는 시스템은 사용하지 않는다.
