# Project Grow 플레이 데모

브라우저에서 바로 실행되는 단일 파일(`index.html`) 데모입니다. 설치나 빌드가 필요 없습니다.

## 실행 방법

`index.html`을 더블클릭해서 브라우저(Chrome 권장)로 엽니다.

## 저장

진행 데이터는 브라우저(localStorage)에 저장됩니다. 처음 접속한 브라우저에서는 항상 새로 시작하며, 설정 → 데이터 초기화로 언제든 처음부터 다시 할 수 있습니다.

## 포함된 기능

전투, 캐릭터/장비 소환, 강화·한계 돌파, 장비 분해, 일일 던전, 미션·출석, 튜토리얼. 자세한 내용은 [14_Demo_Update/Demo_Update.md](../14_Demo_Update/Demo_Update.md)를 참고하세요.
