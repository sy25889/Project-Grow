# Equipment

## 1. 장비 구성

장비 부위는 다음 2개만 사용한다.

- 무기
- 방어구

장신구는 사용하지 않는다.

무기는 공격력 중심, 방어구는 HP와 방어력 중심으로 설계한다. 추가 옵션과 세부 스탯은 필요 시 추후 확장한다.

## 2. 장비 등급

장비 등급은 다음 5단계로 구성한다.

- 일반
- 고급
- 희귀
- 영웅
- 전설

높은 등급일수록 기본 능력치와 성장 효율이 높다. 등급별 정확한 수치 차이는 추후 Balance에서 결정한다.

## 3. 장비 강화

- 장비는 +0부터 시작한다.
- 초기 기준 최대 강화 수치는 +10이다.
- 강화 비용은 골드만 사용한다.
- 강화 실패는 사용하지 않는다.
- 강화 성공 확률은 100%이다.

강화 비용과 단계별 증가 수치는 추후 Balance에서 결정한다. 강화석은 사용하지 않는다.

## 4. 장비 획득 및 중복 장비

장비는 몬스터 처치에서 드랍되지 않는다. 주요 획득 방식은 장비 소환이다.

중복 또는 사용하지 않는 장비는 우선 판매하여 골드를 획득한다. 같은 장비를 합성하는 시스템은 현재 단계에서 사용하지 않으며, 필요 시 추후 확장한다.

## 데모 기준 변경·추가 사항 (2026-10)

플레이 데모를 만들고 테스트하며 바뀌었거나 새로 확정된 내용이다. 위 본문과 다를 경우 이 항목을 기준으로 한다.

### 변경

- 장비 등급 이름은 기존과 같다(일반·고급·희귀·영웅·전설). 장비 소환 확률은 일반 50% / 고급 28% / 희귀 15% / 영웅 6% / 전설 1%이다.
- 강화 비용: `60 × (등급 번호 + 1) × (현재 강화 + 1)` 골드. (등급 번호: 일반 0 ~ 전설 4)
- 최대 강화 +10 → **+15**. +11~+15는 한계 돌파로, 골드와 함께 장비 조각 20 / 30 / 45 / 65 / 90개를 단계별로 사용한다.
- 중복·불필요 장비 처리: 판매 대신 **분해**를 사용한다. 분해하면 장비 조각(일반 2 / 고급 5 / 희귀 12 / 영웅 30 / 전설 80개)과, 그 장비에 투입한 강화 골드의 50%를 돌려받는다.
- 장착: 편성한 캐릭터에게만 장착할 수 있다. 장비 목록에서 장비를 선택한 뒤 장착할 캐릭터(직업·등급 표시)를 고른다.

### 추가

- **분해 UI**: 같은 종류·등급 장비를 수량으로 선택해 분해할 수 있고, 등급별 일괄 분해를 지원한다. 장착 중인 장비는 분해할 수 없고, 영웅 이상이거나 강화된 장비를 분해할 때는 확인 창을 띄운다.
- **장비 조각**: 분해로만 얻는 재화이며 한계 돌파에만 사용한다. 일반 강화에는 장비 조각을 쓰지 않는다. (강화석은 여전히 사용하지 않는다.)
