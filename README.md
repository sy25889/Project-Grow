# 🎮 Project Grow

**개인 게임기획 프로젝트 · 1인 기획 · 진행 중**

> 자동 전투의 편의성은 유지하면서, 직업별 대응 기믹과 파티 편성을 통해 전략성을 더한 3D 방치형 RPG

**기획자: 윤성한**

![Project Grow 인게임 전투 비주얼 콘셉트](09_Character/images/tank_ingame_concept.png)

## 📌 프로젝트 개요

- 장르: 캐주얼 판타지 방치형 RPG
- 플랫폼: Mobile
- 화면 방향: 가로형
- 그래픽 방향: Stylized 3D
- 전투 방식: 4인 파티 자동 전투
- 핵심 컨셉: 거대한 세계수를 올라가며 각 지역의 몬스터와 수호자를 공략하는 모험

## 🌳 세계관

세계의 중심에는 생명을 유지하는 거대한 세계수가 존재한다.

어느 날 세계수 상층에서 정체불명의 오염이 발생하고, 오염은 점차 아래로 퍼지며 세계수에 살던 생명체들에게 영향을 주기 시작한다.

플레이어는 새로운 원정대를 이끄는 지휘관이 되어 다양한 모험가를 영입하고 4명의 파티를 구성해 세계수를 올라간다.

정상에 가까워질수록 세계수의 오염과 세계의 역사에 숨겨진 비밀을 발견하게 된다.

## ✨ 핵심 기획

### 1. 실패해도 멈추지 않는 성장 루프

스테이지 공략에 실패해도 플레이가 종료되지 않는다.

직전에 클리어한 스테이지로 복귀하여 반복 사냥을 진행하고, 성장 재화를 획득한 뒤 캐릭터 성장과 파티 조정을 통해 다시 도전한다.

**플레이 흐름**

자동 전투
→ 스테이지 진행
→ 전투 실패 또는 보스 도달
→ 직전 스테이지 반복 사냥
→ 성장
→ 파티 조합 변경
→ 재도전
→ 상위 스테이지 진행

### 2. 직업 대응 시스템

단순 속성 상성이 아니라 각 직업의 역할에 맞는 전투 대응 기믹을 설계했다.

- 탱커: 피해 감소 / 강공격 대응 / 아군 보호
- 근거리 딜러: 방어 게이지 파괴
- 원거리 딜러: 안정적인 지속 피해 / 후방 대응
- 암살자: 후방 침투 / 적 스킬 차단
- 서포터: 회복 / 적 버프 제거

추천 직업은 강제 조건이 아니라 공략을 더 빠르고 안정적으로 만드는 전략적 선택지이다.

### 3. 캐릭터 성장 시스템

**캐릭터 태생 등급:** B → A → S → SS

- 최대 레벨: Lv.100
- 일반 레벨과 돌파 시스템 분리
- 최대 돌파: ⭐⭐⭐⭐⭐
- 돌파 1회 필요 조각: 20개
- 중복 캐릭터 획득 시 해당 캐릭터 조각 획득

**돌파 방향**

- ⭐ 1돌파: 기본 능력치 대폭 강화
- ⭐⭐ 2돌파: 기본 공격 강화
- ⭐⭐⭐ 3돌파: 일반 스킬 강화
- ⭐⭐⭐⭐ 4돌파: 기본 능력치 추가 강화
- ⭐⭐⭐⭐⭐ 5돌파: 고유 특성 개방 또는 강화

## ⚔️ Boss Design - 세계수 골렘

세계수 골렘은 단순히 높은 능력치를 가진 보스가 아니라 방어 게이지와 Break / Groggy 시스템을 활용한 공략형 보스로 설계했다.

**패턴**

1. 기본 공격
2. 대지 강타
3. 방어 태세
4. 방어 실패 시 강공격
5. 방어 게이지 파괴 시 Break
6. Break 이후 Groggy 상태 진입

근거리 딜러는 방어 게이지 파괴에 유리하며, 탱커는 강공격 대응과 파티 보호에 강점을 가진다.
