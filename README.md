## 📌 프로젝트 개요

- 장르: 캐주얼 판타지 방치형 RPG
- 플랫폼: 모바일 목표 (현재 플레이 데모는 웹 브라우저)
- 화면 방향: 가로형
- 그래픽 방향: 2D
- 전투 시점: 고정형 횡스크롤 2D
- 전투 방식: 4인 파티 자동 전투
- 핵심 컨셉: 거대한 세계수를 올라가며 각 지역의 몬스터와 수호자를 공략하는 모험

## 🌳 세계관

세계의 중심에는 생명을 유지하는 거대한 세계수가 존재한다.

어느 날 세계수 상층에서 정체불명의 오염이 발생하고, 오염은 점차 아래로 퍼지며 세계수에 살던 생명체들에게 영향을 주기 시작한다.

플레이어는 새로운 원정대를 이끄는 지휘관이 되어 다양한 모험가를 영입하고 4명의 파티를 구성해 세계수를 올라간다.

정상에 가까워질수록 세계수의 오염과 세계의 역사에 숨겨진 비밀을 발견하게 된다.

## ✨ 핵심 기획

### 1. 실패해도 멈추지 않는 성장 루프

스테이지 공략에 실패해도 플레이가 종료되지 않는다.

직전에 클리어한 스테이지로 복귀하여 반복 사냥을 진행하고, 성장 재화를 획득한 뒤 캐릭터 성장과 파티 조정을 통해 다시 도전한다.

**플레이 흐름**

자동 전투
→ 스테이지 진행
→ 전투 실패 또는 보스 도달
→ 직전 스테이지 반복 사냥
→ 성장
→ 파티 조합 변경
→ 재도전
→ 상위 스테이지 진행

### 2. 직업 역할과 보스 방어 게이지

5개 직업(탱커, 근접, 원거리, 서포터, 암살자)이 서로 다른 역할을 맡고, 파티는 한 직업당 1명으로 구성한다.

- 탱커: 도발, 피해 감소, 보호막
- 근접: 방어 게이지를 가장 빠르게 깎아 보스 그로기 유도
- 원거리: 안정적인 지속 피해, 전체·저격 공격
- 암살자: 후방·HP가 낮은 적을 노린 순간 피해
- 서포터: 회복, 보호막, 공격력 버프

보스는 방어 게이지가 0이 되면 5초 동안 그로기에 빠져 큰 피해를 받는다. 추천 직업별 전용 효과를 두는 "직업 대응 시스템"은 정식 버전에서 검토한다. ([Combat.md](docs/04_Combat/Combat.md) 참고)

### 3. 캐릭터 성장 시스템

**캐릭터 태생 등급:** B → A → S → SS

- 최대 레벨: Lv.100
- Lv.1~100 골드 기반 레벨업 (HP·공격력 상승)
- 일반 레벨과 돌파 시스템 분리
- 최대 돌파: ⭐⭐⭐⭐⭐
- 돌파 1회 필요 조각: 20개
- 중복 캐릭터 획득 시 해당 캐릭터 조각 20개 획득
- 무기 / 방어구 장착 및 강화 (+15까지, +11부터는 장비 조각 사용)
- 장비 소환을 통한 장비 획득

**돌파 방향**

- ⭐ 1돌파: 기본 능력치 대폭 강화
- ⭐⭐ 2돌파: 기본 공격 강화
- ⭐⭐⭐ 3돌파: 일반 스킬 강화
- ⭐⭐⭐⭐ 4돌파: 기본 능력치 추가 강화
- ⭐⭐⭐⭐⭐ 5돌파: 고유 특성 개방 또는 강화

## ⚔️ Boss Design

보스는 높은 능력치만으로 난이도를 만들지 않고 방어 게이지와 그로기 시스템을 활용한다.

1. 기본 공격
2. 대지 강타 (약 9초마다 파티 전체 피해)
3. 방어 게이지가 0이 되면 BREAK
4. 5초 동안 그로기 상태에서 큰 피해를 받음

근접 직업은 방어 게이지를 빠르게 깎는 데 유리하다. 상세는 [Combat.md](docs/04_Combat/Combat.md)와 [Monster.md](docs/10_Monster/Monster.md)를 참고한다.
