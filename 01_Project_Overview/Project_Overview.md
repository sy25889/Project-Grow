# Project Overview

## 게임 컨셉

- 장르: 캐주얼 판타지 방치형 RPG
- 플랫폼: 모바일 목표 (현재 플레이 데모는 웹 브라우저)
- 화면 방향: 가로형
- 그래픽: 2D
- 전투 시점: 횡스크롤 형태의 고정형 2D 전투 시점
- 전투 방식: 4인 파티 자동 전투
- 핵심 컨셉: 거대한 세계수를 올라가며 다양한 지역과 몬스터, 수호자를 공략하는 모험

## 제작

- 1인 기획·제작 (윤성한). 공모전은 팀 단위 접수 규정에 따라 팀 Memory로 접수했다.
- 기획과 설계 결정은 기획자가 하고, 구현과 테스트는 AI와 반복하는 방식으로 진행했다.

## 세계관 및 스토리

세계의 중심에는 오래전부터 생명을 유지해 온 거대한 **세계수**가 존재한다.

어느 날 세계수의 상층에서 정체불명의 **오염**이 발생하기 시작하고, 오염은 점차 아래로 퍼지며 세계수에 살던 생명체들에게 영향을 미친다.

여러 원정대가 원인을 조사하기 위해 세계수에 도전했지만 아직 누구도 정상에 도달하지 못했다.

플레이어는 새로운 원정대를 이끄는 지휘관이 되어 다양한 모험가를 영입하고 4명의 파티를 구성해 세계수를 올라간다.

## 현재 구현 범위

- 챕터 3개(세계수 숲, 독무 늪지, 불꽃 협곡), 15개 스테이지
- 캐릭터 20명(직업 5종 × 등급 4종)과 소환·성장·돌파
- 장비 소환·강화·한계 돌파·분해
- 일일 던전 3종, 목표 미션, 일일 미션, 출석, 방치 보상
- 튜토리얼과 설정, 자동 저장

## 스토리 방향

- 밝은 모험 판타지를 기본 분위기로 한다.
- 세계수의 정상과 오염의 정체에 대한 미스터리를 함께 제공하되, 플레이를 방해할 정도로 무겁게 전개하지 않는다.
- 챕터마다 서로 다른 환경과 몬스터를 구성한다.
- 오염의 정확한 원인과 정상의 비밀 등 세부 스토리는 추후 확정한다.
