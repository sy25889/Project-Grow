# Stage

## 챕터 구조

하나의 챕터는 일반 스테이지 10개와
별도의 Chapter Boss로 구성한다.

예시:

1-1
→ 1-2
→ 1-3
→ ...
→ 1-10
→ Chapter 1 Boss
→ 2-1

## 일반 스테이지

- 일반 몬스터와 정예 몬스터가 등장할 수 있다.
- 하나 이상의 웨이브로 구성할 수 있다.
- 웨이브 간 별도의 전환 연출을 사용하지 않는다.
- 현재 웨이브의 적을 전멸시키면 다음 웨이브가 바로 등장한다.
- 마지막 웨이브의 적을 전멸시키면 클리어한다.

## 실패 처리

- 일반 스테이지 실패 시 직전 클리어 스테이지로 복귀한다.
- Chapter Boss 실패 시 해당 챕터의 마지막 일반 스테이지로 복귀한다.
- 최고 클리어 기록은 유지한다.

## 난이도 상승

단순히 웨이브 수만 증가시키기보다 다음 요소를 활용한다.

- 몬스터 조합
- 몬스터 수
- 정예 몬스터 등장
- 보스 고유 패턴

과도하게 긴 전투가 되지 않도록
웨이브 수와 전투 시간은 추후 밸런스 단계에서 조정한다.

## 데모 기준 변경·추가 사항 (2026-10)

플레이 데모를 만들고 테스트하며 바뀌었거나 새로 확정된 내용이다. 위 본문과 다를 경우 이 항목을 기준으로 한다.

### 변경 — 챕터 구조 (데모 기준)

- 데모에서는 **한 챕터를 일반 스테이지 4개 + 보스 스테이지 1개(총 5개)**로 구성하고, 3챕터(15개 스테이지)까지 구현했다. 표기는 `챕터-번호`(예: 1-5가 챕터 1 보스)이다. 정식 버전에서는 챕터당 일반 10개 + Chapter Boss 구조로 확장한다.
- 챕터: 1 세계수 숲, 2 독무 늪지, 3 불꽃 협곡
- 스테이지는 5개마다 배경이 바뀐다.

### 추가

- **권장 전투력(스테이지 1~15)**: 500 / 800 / 1,200 / 1,800 / 3,500 / 3,600 / 4,300 / 5,600 / 7,200 / 8,600 / 8,800 / 9,400 / 12,500 / 15,500 / 19,000. 시뮬레이션으로 정한 값이며 플레이 테스트로 조정한다.
- **던전 해금 조건**: 골드 던전 1-3, 장비 던전 1-5, 조각 던전 2-5 클리어
- **실패 처리**: 후퇴한 스테이지에서 반복 사냥하며, 후퇴한 스테이지가 이미 클리어한 곳이면 자동으로 올라가지 않는다. (Gameplay.md 참고)
