# Project Overview

## 게임 컨셉

- 장르: 캐주얼 판타지 방치형 RPG
- 플랫폼: 모바일
- 화면 방향: 가로형
- 그래픽: 2D
- 전투 시점: 횡스크롤 형태의 고정형 2D 전투 시점
- 핵심 컨셉: 거대한 세계수를 올라가며 다양한 지역과 몬스터, 수호자를 공략하는 모험

## 세계관 및 스토리

세계의 중심에는 오래전부터 생명을 유지해 온 거대한 **세계수**가 존재한다.

어느 날 세계수의 상층에서 정체불명의 **오염**이 발생하기 시작하고,
오염은 점차 아래로 퍼지며 세계수에 살던 생명체들에게 영향을 미치기 시작한다.

여러 원정대가 원인을 조사하기 위해 세계수에 도전했지만
아직 누구도 정상에 도달하지 못했다.

플레이어는 새로운 원정대를 이끄는 지휘관이 되어
다양한 모험가를 영입하고 4명의 파티를 구성해 세계수를 올라간다.

세계수의 각 구역과 수호자들을 공략하며 정상에 가까워질수록
세계수의 오염과 세계의 역사에 숨겨진 비밀을 발견하게 된다.

## 스토리 방향

- 밝은 모험 판타지를 기본 분위기로 한다.
- 세계수의 정상과 오염의 정체에 대한 미스터리를 함께 제공한다.
- 스토리가 플레이를 방해할 정도로 무겁게 전개되기보다는 스테이지 진행에 목적과 궁금증을 부여한다.
- 세계수의 각 구역은 서로 다른 환경과 생태계를 가지며 챕터마다 새로운 지역과 몬스터를 구성할 수 있다.

## 현재 설정 상태

세계수, 원정대, 오염, 정상의 미스터리는 기본 컨셉으로 설정한다.

오염의 정확한 원인과 세계수 정상의 비밀 등
세부 스토리는 추후 기획 단계에서 확정한다.
