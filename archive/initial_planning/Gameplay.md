# Gameplay

## 기본 플레이

- 모바일 가로형 방치형 RPG
- 최대 4명의 캐릭터로 파티 구성
- 기본 공격 자동 사용
- 일반 스킬은 조건 또는 쿨타임에 따라 자동 사용

## 스테이지 진행

일반 스테이지는 다음과 같이 진행한다.

1-1
→ 1-2
→ ...
→ 1-10
→ Chapter 1 Boss
→ 2-1

1-10은 일반 스테이지이며,
별도의 Chapter Boss를 클리어해야 다음 챕터로 이동한다.

## 실패 처리

일반 스테이지 실패 시 직전에 클리어한 스테이지로 자동 복귀한다.

예시:

1-8 실패
→ 1-7 복귀
→ 1-7 반복 사냥

Chapter Boss 실패 시 해당 챕터의 마지막 일반 스테이지로 복귀한다.

예시:

Chapter 1 Boss 실패
→ 1-10 복귀
→ 1-10 반복 사냥

최고 클리어 기록은 유지된다.

## 재도전

기본적으로 유저가 직접 다음 스테이지에 재도전할 수 있다.

AUTO 도전 기능을 활성화하면
성장 후 자동으로 다음 스테이지에 다시 도전할 수 있다.
