# 버그 수정 기록

플레이 테스트 중 발견한 문제와 수정 내용을 정리한 기록이다. 각 항목은 증상, 원인, 해결, 확인 방법 순서로 적었다.

## 1. 다른 PC에서 시작 화면 캐릭터가 떨리는 문제

- **증상:** 다운로드해서 다른 컴퓨터에서 열면 시작 화면의 캐릭터가 계속 떨린다.
- **원인:** 캐릭터에 떠다니는 애니메이션과 GPU 가속 관련 속성(`will-change`, `backface-visibility`)을 함께 걸어서, 일부 환경에서 서브픽셀 단위로 흔들렸다.
- **해결:** 해당 애니메이션과 속성을 제거하고 캐릭터를 정지 상태로 표시했다.
- **확인:** 헤드리스 브라우저에서 시작 화면을 열어 흔들림이 없음을 확인했다.

## 2. 윈도우에서 미션 깜빡임, 배너 흔들림, 소환 카드 동시 오픈

- **증상:** 윈도우에서 플레이하니 미션 알림이 매우 빠르게 깜빡이고, 소환·장비 화면의 이미지가 위아래로 빠르게 흔들렸다. 소환 결과 카드도 하나씩 열리지 않고 한꺼번에 열렸다.
- **원인:** "OS가 애니메이션 줄이기 설정이면 모든 애니메이션 시간을 0.01초로, 지연을 0초로 만든다"는 CSS 규칙이 있었다. 반복 애니메이션이 초고속으로 돌고, 카드별 시간차도 사라졌다. 윈도우의 "애니메이션 효과 표시" 설정이 꺼져 있으면 적용된다.
- **해결:** 해당 규칙을 삭제해 설정과 관계없이 같은 연출이 나오게 했다.
- **확인:** 브라우저를 '동작 줄이기' 상태로 두고 확인했다. 배너 주기 4초, 카드 시간차 0.12초 간격으로 정상 동작했다.

## 3. 미션 보상과 스테이지 클리어 보상이 겹쳐 누락처럼 보이는 문제

- **증상:** 미션 조건을 채운 상태에서 스테이지를 클리어하면 두 보상이 한꺼번에 들어와 유저가 보상 누락으로 오해할 수 있다.
- **해결:** 보상을 자동 지급하지 않고 미션마다 완료 버튼으로 하나씩 수령하게 바꿨다. 클리어 보상 창을 복원하고, 다음 스테이지로 넘어가기 버튼 옆에 3, 2, 1 초읽기를 넣어 3초 뒤 자동으로 넘어가게 했다.

## 4. 소환 미션을 수행할 다이아가 없는 문제

- **증상:** 다이아를 다 쓴 뒤 "10회 소환" 같은 미션이 나오면 수행할 수 없다.
- **해결:** 소환 미션 바로 앞 미션의 보상에 다음 소환 비용만큼의 다이아를 미리 포함시켰다. 미션 화면에도 "다음 소환 미션 비용 포함"이라고 표시한다.

## 5. 던전과 장비 소환이 튜토리얼 전에 열리는 문제

- **증상:** 튜토리얼을 마치기 전에 던전이나 장비 메뉴에 들어가 흐름이 꼬일 수 있다.
- **해결:** 던전은 1-3 클리어 시 골드, 1-5 클리어 시 장비, 2-5(10번째 스테이지) 클리어 시 캐릭터 조각 던전이 순서대로 열리게 했다. 새 던전이 열릴 때마다 안내 말풍선을 띄운다. 튜토리얼 중에는 하단 메뉴를 잠가 순서대로 진행하게 했다.
