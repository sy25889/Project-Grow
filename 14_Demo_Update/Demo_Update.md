# 14. 데모 업데이트 기획 (플레이 데모 기준)

플레이 데모(`demo/index.html`)를 만들며 추가·확정한 기획 내용입니다. 기존 기획 문서와 겹치는 항목은 데모에서 실제로 검증한 수치를 기준으로 정리했습니다.

## 1. 설계 원칙

- 방치형이므로 보상을 받기 위해 반드시 눌러야 하는 구조를 두지 않는다.
- 새 기능은 해금되는 시점에 튜토리얼로 안내한다. 튜토리얼 중의 조작은 실제 자원을 소모하지 않는다(소탕, 분해 등은 안내만 하고 실제로 실행하지 않는다).
- 미션이 곧 성장 가이드가 되도록, 튜토리얼과 미션 순서를 연결한다.

## 2. 시작 흐름

1. 게임 시작 시 B등급 전사 1명으로 1-1 스테이지를 진행하고, 왼쪽에 미션 칩이 표시된다. 메뉴는 잠겨 있다.
2. 1-1을 클리어하면 튜토리얼이 시작된다: 캐릭터 무료 5회 소환 → 파티 편성 → 장비 무료 5회 소환 → 장비 장착 → 출석 보상 → 일일 미션 확인.
3. 이후 던전(1-3), 장비 분해, 새 던전 해금 시점마다 별도 튜토리얼이 진행된다.

## 3. 전투 진행

- 클리어 시 보상 창이 뜨고 3초 카운트다운 후 자동으로 다음 스테이지로 이동한다. (재도전, 캐릭터 강화 버튼으로 중단 가능)
- 전멸 시 직전 스테이지로 자동 후퇴한다. 이미 클리어한 스테이지로 후퇴한 경우에는 자동으로 다시 올라가지 않고, 화면의 "▶ N-N 로 넘어가기" 버튼으로 직접 진행한다(반복 사냥 유지).
- 스테이지 보상: 골드 450 × 스테이지 번호. 다이아는 첫 클리어 100 + 30 × 스테이지 번호(5의 배수 보스 스테이지는 +300), 반복 클리어는 20.

## 3-1. 전투력

- 전투력 = round(공격력 × 5 + HP × 0.5), 파티 4명의 합계.
- 스테이지별 권장 전투력을 화면에 표시한다. 수치는 파티 구성과 레벨을 바꿔 가며 전투를 시뮬레이션해 정했다.
- 권장 전투력(스테이지 1~15): 500 / 800 / 1,200 / 1,800 / 3,500 / 3,600 / 4,300 / 5,600 / 7,200 / 8,600 / 8,800 / 9,400 / 12,500 / 15,500 / 19,000

## 4. 소환

- 캐릭터 확률: B 70% / A 24% / S 5% / SS 1%. 천장은 S 이상 50회, SS 100회.
- 10회 소환은 A 이상 1개 보장. 장비 10회 소환은 에픽 이상 1개 보장.
- 비용: 캐릭터 1회 💎150 / 10회 💎1,350, 장비 1회 💎100 / 10회 💎900.
- 중복 캐릭터는 조각으로 변환하고, 조각으로 돌파한다(돌파 1회당 20조각, 최대 5회).
- 파티는 최대 4명이며 한 직업당 1명만 편성할 수 있다.

## 5. 장비

- 강화: +10까지 골드로 강화한다.
- 한계 돌파(+11~+15): 골드와 장비 조각을 소모한다. 필요 장비 조각은 20 / 30 / 45 / 65 / 90.
- 분해: 장비를 분해하면 등급별 장비 조각 2 / 5 / 12 / 30 / 80개와 투자한 강화 골드의 50%를 돌려받는다. 분해 수량을 정하는 방식과 등급별 일괄 분해를 지원한다.
- 에픽 이상이거나 강화된 장비를 분해할 때는 확인 창이 뜬다.

## 6. 던전

- 던전은 하루 3회 입장하며 5단계(Lv.1~5)로 구성된다. 클리어한 단계는 소탕할 수 있다.
- 해금 순서:
  - 골드 던전: 스테이지 1-3 클리어
  - 장비 던전: 스테이지 1-5 클리어 (장비 2개 획득)
  - 조각 던전: 스테이지 2-5(10번째) 클리어 (요일별 직업 캐릭터에게 돌파 조각, 주말은 직업 선택)
- 던전권: 하루 3회를 모두 쓴 뒤에도 던전권 1장으로 도전·소탕할 수 있다. 미션 보상으로 얻는다.
- 던전 중 언제든 "던전 나가기"로 나갈 수 있고, 실패해도 입장 횟수는 줄지 않는다.

## 7. 미션 (키우기 RPG식 연속 미션)

- 전투 화면 왼쪽에 현재 미션이 항상 표시되며, 달성하면 한 번에 하나씩 완료한다. 이미 달성한 다음 미션은 목록에서 "달성"으로 표시된다.
- 초반 미션은 튜토리얼 순서와 같다: 1-1 클리어 → 캐릭터 소환 5회 → 2명 편성 → 장비 소환 5회 → 장비 장착 → 출석 보상 → 팀 레벨 합계 → 1-2, 1-3 클리어(던전 해금) → 던전 클리어 …
- 이후 스테이지 클리어, 전투력, 팀 레벨 합계, 장비 강화 합계, 캐릭터 수집·돌파, 던전별 클리어, 소환, 분해 등 다양한 조건이 이어지며, 40여 개의 지정 미션 뒤에는 목표가 점점 커지는 무한 미션이 반복된다.
- 소환 횟수 미션은 바로 앞 미션의 보상에 소환 비용만큼의 다이아를 포함해서, 재화가 없어 미션을 못 깨는 일이 없도록 한다.
- 보상 종류: 골드, 다이아, 던전권, 장비 조각.

## 8. 일일 미션과 출석

- 7일 출석 보상과 일일 미션(처치, 클리어, 소환, 강화, 던전 등)을 제공한다. 날짜가 바뀌면 초기화된다.

## 9. 개발 과정과 AI 활용

- 기획서와 설계 결정은 기획자가 직접 하고, 구현과 테스트는 AI(Claude)와 반복하는 방식으로 진행했다.
- 튜토리얼, 던전, 미션 흐름은 헤드리스 브라우저로 자동 테스트했고, 권장 전투력은 전투 시뮬레이션으로 보정한 뒤 직접 플레이로 확인했다.

## 10. 남은 과제

- 직업 시너지, 캐릭터별 개성 강화(현재 일부 스프라이트는 색 변형)
- 캐릭터 등급 간 스탯 밸런스 재조정
- 다수 플레이어 테스트를 통한 경제·보상 수치 조정
- 진행 데이터 내보내기/불러오기
