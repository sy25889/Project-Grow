# Gameplay

## 기본 플레이

- 모바일 가로형 방치형 RPG
- 최대 4명의 캐릭터로 파티 구성
- 기본 공격 자동 사용
- 일반 스킬은 조건 또는 쿨타임에 따라 자동 사용

## 스테이지 진행

일반 스테이지는 다음과 같이 진행한다.

1-1
→ 1-2
→ ...
→ 1-10
→ Chapter 1 Boss
→ 2-1

1-10은 일반 스테이지이며,
별도의 Chapter Boss를 클리어해야 다음 챕터로 이동한다.

## 실패 처리

일반 스테이지 실패 시 직전에 클리어한 스테이지로 자동 복귀한다.

예시:

1-8 실패
→ 1-7 복귀
→ 1-7 반복 사냥

Chapter Boss 실패 시 해당 챕터의 마지막 일반 스테이지로 복귀한다.

예시:

Chapter 1 Boss 실패
→ 1-10 복귀
→ 1-10 반복 사냥

최고 클리어 기록은 유지된다.

## 재도전

기본적으로 유저가 직접 다음 스테이지에 재도전할 수 있다.

AUTO 도전 기능을 활성화하면
성장 후 자동으로 다음 스테이지에 다시 도전할 수 있다.

## 데모 기준 변경·추가 사항 (2026-10)

플레이 데모를 만들고 테스트하며 바뀌었거나 새로 확정된 내용이다. 위 본문과 다를 경우 이 항목을 기준으로 한다.

### 변경 — 재도전 방식

- "유저가 직접 다음 스테이지에 재도전"하던 방식에서 **자동 진행**으로 바꾼다. 방치형이므로 직접 눌러야 하는 구조를 두지 않는다.
- 스테이지 클리어 시 보상 창이 뜨고, **3초 카운트다운 후 자동으로 다음 스테이지**로 이동한다. 창의 "재도전", "캐릭터 강화" 버튼으로 중단할 수 있다.
- 전멸하면 직전 스테이지로 자동 후퇴한다. 이미 클리어한 스테이지로 후퇴한 경우에는 자동으로 다시 올라가지 않고, 화면의 "▶ N-N 로 넘어가기" 버튼을 눌러 직접 올라간다. (후퇴한 스테이지에서는 반복 사냥)
- AUTO 도전 설정은 위 자동 진행으로 대체한다.

### 추가

- **튜토리얼**: 1-1을 클리어하면 시작된다. 소환 → 편성 → 장비 소환 → 장착 → 출석 → 일일 미션 순서로 메뉴를 하나씩 열어 준다. 튜토리얼 중에는 해당 메뉴 외에는 잠겨 있다. 던전, 장비 분해, 새 던전 해금도 각각 해금 시점에 튜토리얼로 안내한다. 튜토리얼 조작은 실제 자원을 소모하지 않는다.
- **미션 칩**: 전투 화면 왼쪽에 현재 목표 미션이 항상 표시된다. (14_Demo_Update의 미션 항목 참고)
- **던전**: 하루 3회 입장하는 일일 던전(골드/장비/조각)을 추가한다.
