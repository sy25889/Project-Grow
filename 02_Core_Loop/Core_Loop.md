# Core Loop

## 핵심 플레이 루프

자동 전투
→ 스테이지 진행
→ 전투 실패 또는 보스 도달
→ 직전 스테이지 반복 사냥
→ 보상 획득
→ 캐릭터 성장 및 파티 조정
→ 재도전
→ 상위 스테이지 진행

## 실패 후 성장 루프

스테이지 공략에 실패하면 플레이가 멈추지 않는다.

직전에 클리어한 스테이지로 자동 복귀하여 반복 사냥을 진행하고,
성장에 필요한 자원을 획득한다.

획득한 자원을 이용해 캐릭터를 성장시키거나
파티 구성을 변경한 뒤 다시 도전한다.

## 핵심 방향

- 자동 전투의 편의성을 유지한다.
- 실패해도 성장 루프가 계속된다.
- 파티 구성에 전략적인 선택 요소를 제공한다.
- 추천 직업은 강제가 아니라 공략을 유리하게 만드는 선택지이다.
- 보스전에서는 직업 대응과 파티 조합을 통해 공략 전략을 구성한다.

## 데모 기준 변경·추가 사항 (2026-10)

플레이 데모를 만들고 테스트하며 바뀌었거나 새로 확정된 내용이다. 위 본문과 다를 경우 이 항목을 기준으로 한다.

### 추가 — 성장 가이드 루프

핵심 루프 안에서 유저가 다음 할 일을 잃지 않도록 **목표 미션**을 둔다.

전투
→ 미션 달성 (스테이지 클리어, 소환, 강화, 던전 등)
→ 보상 (골드/다이아/던전권/장비 조각)
→ 성장 및 새 콘텐츠 해금
→ 다음 미션

- 미션은 한 번에 하나씩 표시되고 끝없이 이어진다.
- 초반 미션은 튜토리얼 순서와 같아서 "무엇을 해야 하는지"를 알려 준다.
- 하루 단위로는 일일 미션, 출석, 일일 던전이 접속 동기를 준다.
